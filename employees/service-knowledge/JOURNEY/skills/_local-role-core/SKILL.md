# JOURNEY Local Role Core

## 목적
사용자·운영 여정 검토자의 고정 업무 절차를 제공한다. 외부 스킬이 아직 설치되지 않아도 이 절차는 항상 사용한다.

## 책임
- 첫 방문·핵심 과업·실패·재시도·재방문·지원 흐름 검토

## 실행 절차
1. 사용자 목표와 진입 경로 확인
2. 멈춤·혼란·신뢰 하락 지점 기록
3. 오류 후 복구 행동 확인
4. 운영자·지원자 대응 경로 확인
