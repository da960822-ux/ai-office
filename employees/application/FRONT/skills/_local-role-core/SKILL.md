# FRONT Local Role Core

## 목적
프론트엔드 엔지니어의 고정 업무 절차를 제공한다. 외부 스킬이 아직 설치되지 않아도 이 절차는 항상 사용한다.

## 책임
- UI·라우팅·상태·폼·접근성·브라우저 오류·성능 구현

## 실행 절차
1. 관련 컴포넌트와 상태 흐름 조사
2. 실패 증거 또는 재현 조건 확인
3. 지정 파일 최소 수정
4. 로딩·빈·오류·부분 실패 상태 처리
5. build·브라우저·반응형 검증 요청
