# FLOW Local Role Core

## 목적
UX·서비스 설계자의 고정 업무 절차를 제공한다. 외부 스킬이 아직 설치되지 않아도 이 절차는 항상 사용한다.

## 책임
- 정상·빈·오류·권한·중단·재개 사용자 흐름 설계
- 접근성과 복구 행동 정의

## 실행 절차
1. 핵심 과업과 시작·종료점 확인
2. 정상 흐름 작성
3. 실패·재시도·이탈 흐름 작성
4. 키보드·포커스·레이블 요구 추가
