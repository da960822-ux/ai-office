# PRODUCT BRIEF

## Definition

비전공 부트캠프 참여자가 짧은 아이디어만으로 현실적인 MVP, 기본 시안, 개발 산출물을 만들고 Codex·Claude Code로 이어가는 Guided Product-to-Code Workspace.

## Users

- 1~4명 부트캠프 팀
- 기획 경험이 적은 팀장
- AI 코딩 도구 초급자

## Problem

무엇을 설명하고 어느 범위까지 만들어야 하는지 몰라 생성 결과와 문서가 반복해서 흔들린다.

## Success

사용자가 전문 프롬프트 없이 승인된 MVP와 코딩 에이전트가 시작할 폴더를 얻는다.
