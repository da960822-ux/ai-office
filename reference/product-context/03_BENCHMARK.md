# 03. Benchmark and Product Lessons

## 실제 포지셔닝 (2026-08-06 기준 검증된 것만)

아래 경쟁사 절들은 참고용 아이디어 목록이다. 이름을 댄 경쟁사와의 정량 비교는 이 저장소 어디에도 없다 — **Replit Agent/Genspark 대비 정량 비교는 아직 실측하지 않았다.**

지금 이 코드베이스에서 실제로 동작하는 것으로 확인된 차별화 지점은 "24인 조직 메타포"가 아니라 **실행 신뢰성**(long-running agent execution reliability)이다:

- Job lease/heartbeat로 worker 크래시 후 자동 복구 (`apps/api/worker.py`, `recover_orphaned_jobs`)
- 모델·도구 호출 사이 안전 지점에서 실행 중 pause/cancel (`apps/api/main.py`, `safe_point`)
- 예산 상한 강제, 초과 시 HTTP 402 (`apps/api/main.py`, `check_budget`)
- 부서 순서 파이프라인 게이트: phase가 기획→개발→리뷰 stage 순서로 강제 실행되고 같은 stage는 병렬화 (`apps/api/main.py`, `apply_stage_ordering`, 2026-08-06 추가)
- 권한-도구 게이트: 역할별 도구 접근이 선언만이 아니라 실제로 강제됨 (`apps/api/main.py`, `permission_tool_scope`, 2026-08-06 추가)

## Manifest

### 가져올 것

- 거친 입력을 제품 설명·비전·UX·아키텍처로 구조화
- 단계별 로드맵
- 빌더별 실행 프롬프트
- 결정과 맥락의 지속
- 코드 생성 전 모호함 감소

### 차별화

문서만 제공하지 않고 **실행 가능한 기본 시안**을 함께 제공한다.

## Genspark

### 가져올 것

- 사용자가 모델이나 에이전트를 고르지 않는 자동 라우팅
- 채팅보다 완성 산출물 중심 UI
- 문서·디자인·코드 간 공유 컨텍스트
- 한 요청을 여러 전문 기능으로 자동 분해

### 주의

블랙박스가 되지 않게 선택 이유, 작업 상태, 실패 지점을 보여준다.

## Replit Agent

### 가져올 것

- 평범한 언어 입력
- 코드 변경 전 Plan 모드
- Lite/Economy/Power와 유사한 빠르게/균형/깊게 모드
- Design Canvas와 여러 산출물
- 자동 체크포인트와 롤백
- 작업 보드와 백그라운드 상태

### 차별화

구현 환경 자체보다 **의도·범위·산출물을 안정시키는 중립적 준비 레이어**가 된다.

## v0·Lovable·Bolt

### 가져올 것

- 입력 직후 시각 결과
- 실시간 프리뷰
- 요소를 직접 선택해 수정
- 디자인 토큰·템플릿
- GitHub 동기화
- 빌드·배포로 이어지는 흐름

### 피할 것

제품 범위와 데이터 흐름을 정하지 않은 채 그럴듯한 화면만 쌓지 않는다.

## GitHub Spec Kit·Kiro Specs

### 가져올 것

- Requirements → Design → Tasks
- 단계 승인과 Quick Spec
- 산출물 간 교차 검증
- 작업 의존성 그래프
- 명세를 다음 구현 입력으로 사용

### 초보자 UX로 바꾸기

사용자에게 명세 문법을 요구하지 않고 쉬운 선택을 구조화 문서로 변환한다.

## OpenClaw

### 가져올 것

- 프로젝트별 지속 메모리
- 재사용 Skill Pack
- 작업 보드
- 모델·플랫폼 독립성
- MCP·플러그인 확장 지점

### 피할 것

초기부터 컴퓨터 전체 권한, 상시 자율 실행, 무제한 커뮤니티 스킬을 제공하지 않는다.

## Hermes Agent

### 가져올 것

- 세션 검색과 프로젝트 기억
- 반복 작업을 재사용 스킬로 저장
- 독립 작업의 서브에이전트 병렬화
- 스킬 번들·미리보기·신뢰 수준
- 실행 표면이 달라도 같은 컨텍스트 유지

### 후순위

자동 자기개선은 승인·검증·롤백이 갖춰진 뒤 도입한다.

## JENSEn OS

### 가져올 것

- Plan → Build → Check 역할 분리
- 제안만/승인 후 실행/안전 작업 자동의 자율성 수준
- 실행 가시성과 감사 로그
- 중요 작업 승인
- 전체 중단과 복구

### 포지셔닝 주의

`AI 회사 운영체제`보다 `아이디어를 만들 수 있는 첫 버전으로 바꾼다`를 앞세운다.

## MetaGPT·ChatDev·CrewAI

### 가져올 것

- 역할별 산출물 소유권
- 자유 회의보다 SOP와 구조화 handoff
- 중간 검증 게이트
- 순차·계층·병렬 워크플로
- 사람 승인과 관찰 가능성

### 피할 것

CEO·CTO·개발자의 긴 대화를 핵심 경험으로 만들지 않는다. 결정, 근거, 산출물, 검토 결과만 요약한다.

## 최종 필수 8개

1. 간단한 의도 입력
2. 추천 기본값과 최소 질문
3. 범위 통제
4. 즉시 확인 가능한 시안
5. 구조화된 산출물
6. 검토·체크포인트·복구
7. 도구 중립적 인계
8. 에이전트와 비용의 자동 라우팅

## 초기 비필수

- 수십 명의 에이전트
- 완전 자율 회사
- 상시 실행
- 거대한 스킬 마켓
- 모든 개발 스택
- 복잡한 3D 오피스
- 자동 마케팅·결제·운영
