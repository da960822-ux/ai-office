## 확인된 실패 원인

TASK-008은 워커 응답과 웹 출처를 데이터베이스에만 저장했다. 실제 `write_file` 호출은 0회였으며 최종 통합 단계도 없었다. 실행이 끝나면 부서별 상충안을 그대로 팀장 리뷰에 전달했다. 반려 후 재통합 작업도 생성되지 않았다.

시장조사 분류어가 좁아 “틈새시장”, “신규 사업”, “아이템 추천”, “사업화 계획” 요청이 전용 프로필에 걸리지 않았다. 그 결과 제품·UI 워커와 관련 스킬이 시장조사에 섞였고, 작업공간의 무관한 HWP 문서까지 사업 아이템 추론 근거로 사용됐다.

## 적용한 업무 경계

8개 부서, 24명 전원에게 소유 업무와 필수 인계 범위를 지정했다.

1. 운영·기획: 요청 정규화, 계약, 라우팅, 일정·예산
2. 제품·경험: 문제 정의, PRD, 수용 기준, UX/UI 명세
3. 애플리케이션: 기술 설계, 프런트·백엔드 구현
4. AI·데이터: AI 구조, 검색·데이터 파이프라인, 평가
5. 플랫폼·신뢰성: 배포, CI/CD, 관측성, 비용
6. 품질·보안: 독립 시험, 보안·개인정보, 증거 게이트
7. 성장·마케팅: 시장·고객 조사, 포지셔닝, 카피, 분석
8. 서비스·지식: 여정 검토, 문서화, 지식 패키징

팀장은 자기 부서 워커만 배정할 수 있다. 다른 부서 업무는 흡수하지 않고 해당 부서로 넘기도록 실행 프롬프트와 회의 프롬프트에 경계를 주입했다.

## 동적 업무 판단

업무 종류별 키워드·팀·워커·스킬 하드코딩을 제거했다. `task-profiles.json`에는 정적 업무 프로필이 0개다.

GLM 5.2가 매 요청마다 조직의 부서 소유권, 사용 가능한 직원과 스킬, 산출물 기준을 함께 보고 다음 내용을 동적으로 결정한다.

- 필요한 부서와 제외할 부서
- 단계별 목적·의존성·인계 대상
- 최종 통합 책임자
- 작업공간 파일의 무관·읽기·쓰기 범위
- 웹 조사의 필요 여부와 출처 품질·최신성·교차검증 전략
- 최종 산출물 유형

각 팀장은 자기 부서 안에서 필요한 워커만 선택하고, 워커별 업무에 직접 필요한 스킬을 최대 3개까지 동적으로 배정한다. DeepSeek는 이 범위와 인계 계약 안에서 실행한다.

웹 검색 결과의 제목·스니펫은 후보일 뿐 근거로 승인하지 않는다. 조사 업무는 검색 후 선택한 공개 원문을 실제로 읽어야 완료되며, 최종 통합과 리뷰에는 원문 확인을 마친 URL만 전달한다.

## 산출물 완료 게이트

새 업무 흐름은 다음 순서를 강제한다.

1. 각 실행자의 응답을 `AI_OFFICE_OUTPUTS/<TASK-ID>/departments/<EMPLOYEE>.md`에 실제 파일로 저장
2. 지정된 최종 책임자가 부서 초안을 하나의 `FINAL.md`로 통합
3. 팀장 리뷰가 데이터베이스 요약이 아니라 실제 `FINAL.md` 파일을 검수
4. `changes_requested`이면 리뷰 지적을 넣어 자동 재통합
5. 실제 파일이 존재하고 리뷰가 통과해야만 업무를 `completed` 처리

사용자가 지정한 프로젝트를 `in_place` 작업공간으로 사용하며, UI에 산출물 상태·소유자·실제 경로를 표시한다.

## 문서·산출물 기준

8개 산출물 유형의 파일명, 필수 섹션, 검수 규칙을 `registry/deliverable-standards.json`에 등록했다. DOCS에는 `document-artifact-production` 스킬을 추가했다. 이 스킬은 채팅 답변을 산출물로 인정하지 않으며, 파일 존재·필수 섹션·출처·형식별 렌더/구조 QA를 요구한다.

## 스킬 정리

잘못 배치된 다음 스킬을 해당 직원에게서 해제했다.

- LENS: `impeccable`, `ui-ux-pro-max`
- JOURNEY: `ui-ux-pro-max`
- VOICE: `design-first-ui-prompting`

PULSE는 `analytics`만 기본 로드한다. `ab-testing`, `cro`, `seo-audit`은 관련 업무에서만 선택적으로 로드한다. 제거한 폴더는 복구 가능하게 `.cache/removed-skills-20260729/`에 보관했다.

DOCS에는 새 로컬 문서 산출물 스킬을 설치하고 lock hash를 등록했다. 전역 PDF 스킬도 설치했다.
