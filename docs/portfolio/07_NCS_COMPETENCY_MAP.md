# NCS 역량 매핑: AI Office (Corporate OS v6.2)

공기업·준정부기관 등 NCS 기반 채용에 지원할 경우에만 사용. 일반 사기업 IT PM 채용에서는 필수가 아니므로, 지원 대상이 공공기관이 아니라면 이 문서는 참고용으로만 보면 된다.

분류 경로와 능력단위명은 [ncs.go.kr](https://www.ncs.go.kr/index.do)에서 확인한 일반 분류 체계를 기준으로 작성했다. 실제 지원 공고에 명시된 정확한 NCS 코드(대분류-중분류-소분류-세분류 8자리)는 해당 공고문에서 다시 확인해야 한다.

## 관련 NCS 분류 경로 두 가지

이 프로젝트는 성격상 두 분류 모두에 걸쳐 있다.

| 분류 | 경로 |
|---|---|
| ① 정보통신 | 정보통신 > 정보기술 > 정보기술관리 > IT프로젝트관리 |
| ② 사업관리 | 사업관리 > 프로젝트관리 |

## 능력단위 매핑

| NCS 능력단위 | 관련 프로젝트 경험 | 변환 서술 |
|---|---|---|
| 프로젝트 전략기획 | 비목표(멀티테넌트·자동 배포·무제한 자율 실행 제외) 선언, 9일 스코프 결정 | "프로젝트 목표를 로컬·단일 사용자 실행 환경으로 명확히 좁히고 비목표를 문서화해, 9일 개발 기간 내 핵심 문제(증거 기반 완료 판정)에 자원을 집중" |
| 프로젝트 통합관리 | Task/Job 상태 분리 설계, 증거 게이트(hash·검증 명령·독립 리뷰) 설계 | "여러 실행 단계(회의·실행·리뷰·통합)를 하나의 완료 판정 기준으로 통합 관리하는 아키텍처를 설계·구현" |
| 프로젝트 범위관리 | 부서 소유권 경계 정의(`department-boundaries.json`), 부서 간 업무 이관 규칙 설계 | "8개 부서·24개 역할의 소유 범위를 정의해 업무 중복·누락 없이 이관되도록 설계, 정합성 검사 스크립트로 검증" |
| 프로젝트 일정관리 | 9일 내 49개 커밋 단위로 기능을 순차 구현, 각 커밋이 독립적으로 검증 가능하도록 분할 | "짧은 개발 주기 안에서 기능 단위를 작게 쪼개 매 커밋마다 검증 가능한 상태를 유지하며 진행" |
| 프로젝트 리스크관리 | 조용한 실패(silent failure) 유형 버그 6건을 발견해 각각 원인·해결·재발 방지책 문서화 | "개발 중 발견한 리스크(설정 누락, 게이트 우회, 무력화된 테스트)를 트러블슈팅 문서로 체계화해 재발 방지 체크리스트로 전환" |
| 프로젝트 품질관리 | 정적 정합성 검사 스크립트 3종 자체 구축(`verify_routing.py`, `verify_skills.py`, `audit_package.py`) | "코드 리뷰만으로는 못 잡는 설정 누락·해시 불일치를 기계적으로 검출하는 품질 게이트를 직접 설계·구축" |

## 직업기초능력 10개 영역 중 이 프로젝트로 뒷받침 가능한 항목

| 영역 | 근거 |
|---|---|
| 문제해결능력 | 크로스플랫폼 해시 불일치 사건에서 증상 하나(해시 불일치)를 원인 2개(경로 직렬화, CRLF)로 분리 진단하고 각각 다르게 해결 |
| 정보능력 | ripgrep 기반 코드 탐색, Pyright 진단, 정적 정합성 검사 스크립트로 정보 수집·분석·관리 체계 구축 |
| 기술능력 | FastAPI·SQLite(WAL)·React/Vite/TS 스택을 조합해 다중 프로세스 실행 엔진과 관제 UI를 직접 구현 |
| 자원관리능력 | SQLite 원자적 lease·heartbeat로 다중 worker 프로세스 자원을 관리하고, worker 장애 시 자동 복구되도록 설계 |
| 조직이해능력 | 8개 부서·24개 역할의 소유권 경계와 인계 규칙을 설계해 조직 구조 자체를 시스템으로 모델링 |

## 사용 방법

1. 실제 지원 공고에서 요구하는 정확한 NCS 세분류 코드를 `ncs.go.kr`에서 재확인한다.
2. 위 표의 "변환 서술"을 자기소개서 문항(문제해결 경험, 팀워크 경험 등)에 맞춰 재배치한다.
3. 문항이 "협업/팀워크"를 물으면, 이 프로젝트는 1인 개발이므로 위 매핑에서 억지로 끌어오지 말고 다른 팀 경험(있다면)을 우선 사용한다. 이 프로젝트는 조직 설계·품질관리·문제해결 계열 문항에 더 적합하다.
